# 星星收集社

一款輕鬆可愛的繁體中文點擊收集小遊戲。開啟 [`outputs/index.html`](outputs/index.html) 就能遊玩。

## 遊玩方式

在 30 秒內點擊飄浮的星星收集分數；金色星星可得雙倍分數。遊戲支援滑鼠與觸控，最佳紀錄保存在目前瀏覽器。

## GitHub Pages 發布

每次推送到 `main` 後，GitHub Actions 會自動將 `outputs/` 發布到 GitHub Pages。首次設定時，請在 GitHub repository 的 **Settings → Pages → Build and deployment** 選擇 **GitHub Actions**。也可從 Actions 頁面手動執行 `Deploy to GitHub Pages`。

遊戲原始檔位於 `outputs/index.html`；規劃文件位於 `knowledge/plan.md`。
