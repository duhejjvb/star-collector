# 星星收集社：願景與路線圖

## 願景

打造一款打開瀏覽器就能玩的輕鬆休閒小遊戲。玩家在短短一局裡點擊飄過的星星，享受柔和、可愛、沒有壓力的收集體驗；操作同時適合滑鼠與觸控，並能透過個人最佳紀錄鼓勵再次遊玩。

## 遊戲概要

- **名稱：** 星星收集社
- **玩法：** 在限時一局中點擊遊戲區內出現的星星來累積分數。
- **特殊星星：** 金色星星提供雙倍分數。
- **操作：** 滑鼠點擊、觸控輕點，或鍵盤 Tab 選取後按 Enter。
- **美術方向：** 暖色奶油底、柔和天空與草地、漂浮星星和簡短的愉快回饋；支援減少動態效果偏好。
- **紀錄：** 在瀏覽器本機保存個人最佳分數；儲存不可用時仍可遊玩。

## 路線圖

**第一版已透過 GitHub Pages 上線。** Actions 部署工作成功，正式網址回應 HTTP 200。遊戲已補上鍵盤焦點提示、減少動態效果支援、本機儲存失敗時的容錯、頁面縮放與短螢幕捲動，並以單調時鐘校正背景分頁的倒數，且每顆星星只能計分一次。Node.js smoke test 覆蓋分數、紀錄、分頁隱藏與音效狀態；仍需實機驗收桌面與手機的視覺和觸控手感。
