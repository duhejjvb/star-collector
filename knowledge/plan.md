# 星星收集社：願景與路線圖

## 願景

打造一款打開瀏覽器就能玩的輕鬆休閒小遊戲。玩家在短短一局裡點擊飄過的星星，享受柔和、可愛、沒有壓力的收集體驗；操作同時適合滑鼠與觸控，並能透過個人最佳紀錄鼓勵再次遊玩。

## 遊戲概要

- **名稱：** 星星收集社
- **玩法：** 在限時一局中點擊遊戲區內出現的星星來累積分數。
- **特殊星星：** 金色星星提供雙倍分數。
- **操作：** 滑鼠點擊、觸控輕點，或鍵盤 Tab 選取後按 Enter。
- **美術方向：** 暖色奶油底、柔和天空與草地、漂浮星星和簡短的愉快回饋；支援減少動態效果偏好。
- **紀錄：** 在瀏覽器本機保存個人最佳分數；儲存不可用時仍可遊玩。

## 路線圖

### 目前狀態

**第一版已透過 GitHub Pages 上線。** 正式網址回應 HTTP 200。除 Node.js smoke test 外，已在內嵌瀏覽器分別以 1024×768 與 390×844 CSS viewport 檢查實際版面與互動：桌面尺寸完成一局並確認普通星星 +1、30 秒結算、重玩與最佳紀錄；手機尺寸的結算卡完整顯示。鍵盤 Tab/Enter 可開始及收集星星，並修正收集後焦點流失，讓焦點留在下一個目標或遊戲區。音效開關可及狀態能關閉再開啟。這些 viewport 驗收不能代替實體手機觸控或實際聽音效。
